## How this repo works

- **LeetCode**: fully automatic. A scheduled GitHub Action checks for newly accepted submissions, pulls the actual code, and commits it here — no manual file creation needed.
- **Other platforms** (GFG, Codeforces, etc.): add the file under a folder named after the platform (e.g. `gfg/`), with one line at the top:
  `// Problem: <Title> | Platform: <Platform> | Difficulty: <Easy/Medium/Hard> | Link: <url>`
